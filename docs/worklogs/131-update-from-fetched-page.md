# 取得済みページから状態を更新する操作の名前を明確にした

[Issue #131](https://github.com/shigaresso/player-lens/issues/131) に対応した。PR #130 統合済みの origin/main（1b56e54）から codex/131-update-from-fetched-page を作成した。

CollectionState.AddPage を UpdateFromFetchedPage に改名した。取得済みページを基に既存の状態を更新する操作であることを表し、成功ページ数・レビューと既読 ID・既読カーソル・次回カーソル・終了理由が更新対象であることをコメントへ明記した。全項目を無条件に更新する意味ではなく、従来の終了判断と早期 return を維持した。

application と既存テストの呼び出し元、収集仕様・ADR-0014・操作一覧を新しい名前に揃えた。更新項目・処理・戻り値・失敗理由・終了優先順・ファイル配置は変更せず、旧名の互換ラッパーは残していない。NextFetchConditions の非変更・読み取り専用の契約も維持した。過去の作業記録は当時の名前を保持した。
