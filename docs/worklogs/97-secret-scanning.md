## Red・Green の記録

| 契約 | 確認した Red | 確認した Green |
| --- | --- | --- |
| 候補・診断の実値を出さない検査実行 | check_secrets モジュール・CLI が未実装で失敗した | 検出候補を安全な位置情報だけで返し、生の診断を伏せ、一時結果を削除した |
| 破損結果を成功としない | 不正な結果の要素で AttributeError/TypeError になった | 結果の型を検証し、失敗として扱った |
| 中間コミットを検査する | check_commits が未実装で失敗した | 実 Gitleaks が追加後に削除されたダミー資格情報を検出した |
| コミットメッセージを検査する | 差分だけの検査ではメッセージ内の候補を検出せず、期待した失敗にならなかった | 実 Gitleaks の stdin 検査を追加し、候補を検出した |
| message・history・pre-push の CLI | 各未実装サブコマンドが argparse で失敗した | 同じ安全な実行処理で、メッセージ・履歴・送信対象を検査した |
| 実フックで候補を拒否し後続を止める | 接続前は候補を受け付け、3件の期待した拒否が失敗した | 接続後は3件成功し、既存の検査と合わせた11件も成功した |
| 既存規約の診断を維持する | CLI の汎用エラーで「タイトル」の診断が失われ、既存テストが失敗した | 実値を含まない既存の規約エラーを保持して成功した |

フックの拒否テストでは、テスト用検査処理が import 時まで失敗していた誤りを修正した。外部から CLI として呼ばれた場合だけ失敗させ、接続前に3件とも意図した理由で Red になることを確認してから本体を変更した。

初回・部分ステージ等の追加確認は、既存の実装で Green だったため、形式的な失敗を作らずテストのみのコミットにした。検出用の文字列は実在する資格情報を使わず、一時リポジトリ内で組み立てた。実値を Git・作業記録に保存していない。

- 通常の Python テスト：182件成功した。実 Gitleaks を要求する契約テストとは分離した。
- python3 scripts/verify_secrets.py：実 Gitleaks と Git の8テストが成功した。初回・部分ステージの両方向、中間コミット、マージ解決、メッセージ、正常な履歴、空更新・削除を確認し、index・作業ツリーと出力の秘匿を確認した。
